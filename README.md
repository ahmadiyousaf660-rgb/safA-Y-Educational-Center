## Included
- Student login/profile demo
- AI Conversation
- Speaking Coach + microphone support
- Grammar Lab
- Vocabulary practice
- Online English test + score
- Progress dashboard
- Certificate / Diploma generator
- About / Founder & Developer section
- Teacher/Admin dashboard UI
- Responsive mobile + computer design
- SEO metadata, robots.txt, sitemap.xml and PWA manifest
- Secure server-side OpenAI API integration

## Render
- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: blank

Environment variables:
- `OPENAI_API_KEY` = your real API key
- `OPENAI_MODEL` = your supported OpenAI model

Never put a real API key in GitHub or frontend JavaScript.

## Local
